# CLAUDE.md

This repository is a documentary editing system for a history, culture and
geography channel (Balochistan, Pakistan, heritage). The owner records talking-head
footage in a real studio, with no green screen, and expects a finished,
directed documentary edit back.

**The standing brief is [docs/DIRECTING_BRIEF.md](docs/DIRECTING_BRIEF.md). Read
it before any editing work.** The owner should not have to repeat it.

## When the owner provides footage

Follow [docs/WORKFLOW.md](docs/WORKFLOW.md):

1. `python -m docedit run <raw> -o projects/<slug> --assets assets/ --title "<title>" --stop-after-plan`
2. **Direct.** Read the whole clean transcript, then rewrite `projects/<slug>/plan.json`
   as a documentary director would. The auto-plan is only a first draft.
   * Pick the hook. Use `--cold-open` if a later line is the stronger opener.
   * Name the sections and set the music mood per section (including silence).
   * Show what is said: maps for geography, timelines for runs of dates, stats
     for numbers, quotes, B-roll from licensed assets.
   * Let the presenter own decisive and emotional lines: close framing with
     `push_in`, no text.
   * Write captions in English, four words or fewer, editorial rather than
     subtitles.
   * Remove anything that does not help the viewer understand, feel or remember.
3. **Fact-check** every date, number, name and map stop before rendering. If
   you are unsure, say so to the owner and do not put it on screen.
4. **Source visuals** following the licence order in the brief. Record each file
   in `assets/ledger.json`. Write AI prompts for gaps (see `shot_list.md`), and
   mark AI images of the past `"depicts": "historical"`.
5. `render --preview`, look at frames, `render`, then `qc`. Deliver only when QC
   has no FAIL. Report the WARN items and `credits.txt` to the owner.

## Non-negotiables (enforced in code; keep them that way)

* **The face is protected.** No text, graphic or panel may touch the face zone
  (`faces.protected`). When there is no safe space, drop the element; never
  move it onto the face. `qc.py` checks this from `render_log.json`.
* **Copyright.** Only assets with a permitted, recorded licence
  (`licenses.ALLOWED`) are used. NC/ND licences, unknown sources and watermarked
  files are rejected. Music and SFX are generated by the code unless a licensed
  track is in the ledger. Never add downloaded media without a ledger entry.
* **No fabricated evidence.** AI reconstructions are labelled. Maps use Natural
  Earth (public domain, Pakistan point-of-view boundaries). Curated site
  coordinates are approximate.
* **English only on screen.** Captions are English and appear only where they
  help. Translate Urdu lines into English captions when directing. Non-Latin text
  is dropped by the renderer.
* **Clean voice.** QC requires pauses at or below -55 dBFS after cleanup. Don't
  weaken this; use `--denoise strong` instead.
* **Restraint.** Keep the rationed SFX, the minimum presenter gap between
  visuals, and the 4-word caption limit. Busy is not beautiful.

## Code map

| Module | Role |
|---|---|
| `docedit/transcribe.py` | faster-whisper word timestamps, or import JSON/SRT |
| `docedit/cleanup.py` | fillers, stutters, retakes (later take wins), pause tightening, cold open |
| `docedit/faces.py` | face track, smoothing, protected zones |
| `docedit/director.py` | auto-plan: entities, beat scheduling, layouts, music moods, SFX, B-roll requests |
| `docedit/gazetteer.py` | place lookup (English and Urdu names) over `data/geo_region.json` + `data/places_extra.json` |
| `docedit/graphics.py` | map journeys, year reveals, stat counters, quotes, timelines, Ken Burns, video B-roll |
| `docedit/render.py` | clean-take assembly and grade; virtual camera; face-safe compositor |
| `docedit/voice.py` | measured voice restoration (hum, hiss, clicks, sibilance) before cutting |
| `docedit/audio.py` | generated score and SFX; voice chain; ducking; loudness to -14 LUFS |
| `docedit/licenses.py` | asset ledger and licence policy |
| `docedit/qc.py` | executable QC checklist, which writes `qc_report.md` |
| `docedit/style.py` | the channel's visual identity (colours, fonts, timing) |

## Dev

```bash
pip install -r requirements.txt     # opencv must stay < 5 (Haar cascades)
python -m pytest -q                 # includes an end-to-end render on synthetic footage
```

To rebuild the map data: `python tools/build_geodata.py <dir with Natural Earth geojson>`.

# docedit: raw talking-head footage to a directed documentary edit

`docedit` takes studio talking-head footage, with no green screen, and produces a
documentary-style edit. Its rules come from [docs/DIRECTING_BRIEF.md](docs/DIRECTING_BRIEF.md).

* **One clean performance.** It removes fillers (English and Urdu), stutters,
  retakes and false starts (the later take wins), tightens dead air but keeps
  sentence breaths and paragraph beats, and can play an optional cold-open hook
  first. Every cut is logged with its reason.
* **The face is protected.** It tracks the face and computes a protected zone.
  Every caption and panel is placed outside it, or dropped. Layouts are full
  presenter, split (presenter keeps the face side), picture-in-picture, or
  full-screen visual.
* **Directed visuals.** It reads the narration and shows what is said:
  * animated **maps** with Pakistan point-of-view boundaries, province highlight,
    pins, context towns and a camera that flies from stop to stop
  * **year reveals** and **timelines**
  * counting **statistics**
  * **quote cards**
  * Ken Burns **B-roll** from licensed assets
  * short English editorial captions
  * framing changes (wide/medium/close, push-ins) that hide jump cuts and stress
    key lines
* **Copyright-safe sound.** The music beds are original and synthesised per mood
  (documentary, journey, discovery, emotional, tension, cultural). The whoosh and
  impact SFX are generated and rationed. Music is ducked under the voice, and the
  voice is cleaned (high-pass, denoise, EQ, compression). The mix is normalised to
  -14 LUFS.
* **Licence ledger.** Only assets with a permitted, recorded licence are used.
  Credits and an asset log are written for the description.
* **Executable QC.** It checks editing, visuals, face safety, audio and copyright,
  and writes `qc_report.md`.

## Quick start

```bash
pip install -r requirements.txt          # also needs ffmpeg on PATH
python -m docedit run raw.mp4 -o projects/quetta --assets assets/ --title "Quetta" --stop-after-plan
# review/direct projects/quetta/plan.json (see docs/WORKFLOW.md), then:
python -m docedit render -o projects/quetta --assets assets/ --preview
python -m docedit render -o projects/quetta --assets assets/
python -m docedit qc     -o projects/quetta --assets assets/
```

Outputs in the project folder:

| File | What it is |
|---|---|
| `final.mp4` | 1080p master (`preview.mp4` is the 720p check) |
| `edit_report.md` | Beat-by-beat plan: layout, visual, text, and the reason for each |
| `shot_list.md` | Gaps that need B-roll, with search terms and AI prompts |
| `cleanup.json` | Every removed word and tightened pause, with reasons |
| `render_log.json` | Where every element was placed, and what was dropped to protect the face |
| `qc_report.md` | PASS / WARN / FAIL checklist |
| `credits.txt`, `asset_log.json` | Attribution and licence record |

## Honest limits

* **No built-in AI image or video generation, and no stock search.** The tool
  writes prompts and search terms into `shot_list.md`. You add the results to
  `assets/` with a ledger entry.
* **No terrain or satellite imagery yet.** Maps are clean vector maps. Licensed
  satellite stills (for example Sentinel-2 or NASA public-domain imagery) can be
  added as B-roll assets.
* **Transcription quality decides cut quality.** Whisper `large-v3` is
  recommended, especially for Urdu. Check `cleanup.json` on the first few videos.
* **Captions are English.** Urdu-script captions would need a Nastaliq font and a
  text-shaping engine. Urdu narration still triggers maps, stats and dates.
* **Face tracking** uses OpenCV cascades. Profile and backlit shots can be missed.
  When that happens the code protects the centre of the frame instead, so a miss
  makes layouts more cautious, never less.

## Data and licences

* Map data: [Natural Earth](https://www.naturalearthdata.com/) (public domain).
  Country outlines use the Pakistan point-of-view layer. Verify disputed-boundary
  depictions against official Survey of Pakistan maps before publishing.
* Fonts: Oswald and Source Sans 3, both SIL Open Font License (see
  `docedit/data/fonts/`).
* Music and SFX are generated by `docedit/audio.py`, so no third-party audio is
  included.
